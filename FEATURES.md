# Features

## Product and customer visibility

The dashboard reports which customer accounts have services using each native WHMCS product. It shows the product, product ID, customer identity, company, email address, domain or service username, service ID, client status, service status, billing cycle, server, signup date, and next due date.

## Comprehensive filters

Administrators can combine product group, product/package, service status, client status, billing cycle, server, signup date range, next due date range, and free-text search. Search covers customer first name, last name, company, email, domain, username, and product name.

## Administration workflow

The addon includes native WHMCS client and service links, result counts, distinct customer counts, active-service counts, 20-row pagination, numbered navigation, a reset action, and a visible result range.

## Lightweight implementation

The module uses no custom CSS, external assets, JavaScript framework, Composer package, custom table, scheduled process, hook, API credential, or client-area output. It uses default WHMCS admin classes and limits queries to the data required for the report.

## Operational boundaries

This release is a read-only reporting addon. It does not change product assignments, provision services, alter billing status, or reconstruct orders that never resulted in a native WHMCS service record.
